  - 字数：约2000字

03_请假制度.txt
  - 内容：请假类型、流程、审批权限、待遇标准
  - 字数：约1500字
  - 用途：测试制度规范类问题

04_财务报销流程.txt
  - 内容：费用类型、报销流程、发票要求、违规处理
  - 字数：约1800字
  - 用途：测试财务流程查询

05_IT资产管理.txt
  - 内容：设备配置、采购流程、维护维修、报废处置
  - 字数：约1600字
  - 用途：测试IT设备相关问题

06_数据安全规范.txt
  - 内容：数据分类、访问控制、存储要求、违规处理
  - 字数：约1700字
  - 用途：测试安全合规类查询

🎯 测试问题示例：

基础查询：
- 公司什么时候成立的？
- 公司的主要业务是什么？
- 公司总部在哪里？
- 如何联系公司？

人力资源：
- 新员工入职需要什么证件？
- 试用期是多久？
- 年假有多少天？
- 怎么申请请假？
- 病假工资怎么算？

财务相关：
- 差旅费包括哪些？
- 住宿费报销标准是多少？
- 发票抬头怎么写？
- 报销需要多久提交？

IT 设备：
- 公司给配什么电脑？
- 电脑坏了怎么报修？
- 能不能带电脑回家办公？
- IT 资产怎么领用？

数据安全：
- 什么是绝密级数据？
- 密码有什么要求？
- 能不能把工作数据存到个人云盘？
- 数据泄露怎么处理？

🚀 使用方法：

1. 运行构建命令：
   python -m enterprise_rag.main --mode build

2. 系统会自动：
   - 读取本目录下所有 .txt 文件
   - 将文档分割成小块（500字/块）
   - 调用 Embedding 模型向量化
   - 存储到 Milvus 向量数据库

3. 构建完成后可以：
   - 启动 API 服务进行问答测试
   - 启动 Web 界面交互体验
