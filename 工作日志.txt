================================================================
                       技术实现细节
================================================================

【配置系统】
- 使用 dataclass 定义配置类
- 支持预定义配置（EMBEDDING_CONFIGS、LLM_CONFIGS、MILVUS_CONFIGS）
- 从字典/环境变量加载配置

【文档处理】
- 支持 TXT、MD、PDF、DOCX、XLSX、PPTX
- OCR 支持（PaddleOCR）
- 网页爬取（BeautifulSoup）
- 智能分块（多种分隔符策略）

【向量化】
- 支持 sentence-transformers
- 支持 FlagEmbedding（BGE 系列）
- 支持 pymilvus 内置模型
- 向量缓存机制

【检索系统】
- 向量检索：Milvus + HNSW 索引
- 混合检索：向量 + BM25 全文检索
- RRF 融合算法
- BGE-Reranker 重排序

【问答链】
- 基础 QA 链
- 对话式 QA 链（支持多轮）
- LangGraph 复杂流程图
- 查询改写
- 流式输出

【API 服务】
- FastAPI 框架
- RESTful 接口
- SSE 流式输出
- CORS 支持
- 异常处理

【前端界面】
- Streamlit 框架
- 聊天界面
- 侧边栏配置
- 来源展示

================================================================
                        设计模式
================================================================

1. 模块化设计
   - 每个模块独立，职责单一
   - 通过 __init__.py 导出公共接口

2. 延迟加载
   - 模型延迟初始化（@property）
   - 减少启动时间

3. 策略模式
   - 多种 Embedding 模型可切换
   - 多种 LLM 提供商可切换
   - 多种检索策略

4. 依赖注入
   - 检索器依赖 EmbeddingService
   - QA 链依赖检索器和 LLM 配置

5. 工厂模式
   - create_qa_chain() 工厂函数
   - create_embedding_service() 工厂函数

================================================================
                      使用说明
================================================================

【安装】
cd enterprise_rag
pip install -r requirements.txt

【配置】
cp .env.example .env
# 编辑 .env 填入 API Key

【构建知识库】
python -m enterprise_rag.main --mode build

【启动 API 服务】
python -m enterprise_rag.main --mode api

【启动 Web 界面】
python -m enterprise_rag.main --mode frontend

【测试】
pytest tests/
